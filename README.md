# Just24You India — RO, AC, Refrigerator & Geyser Service Platform

Just24You India is a comprehensive multi-appliance care platform built with **React**, **TypeScript**, and **Tailwind CSS**. It covers sales, periodic maintenance, AMC subscriptions, and verified doorstep repair for **RO Water Purifiers**, **Air Conditioners (AC)**, **Refrigerators (Fridges)**, and **Geysers (Water Heaters)**.

---

## 🌟 Key Features & Updates

1. **Multi-Appliance Ecosystem (RO, AC, Fridge, Geyser)**:
   * **RO Water Purifier**: Multi-stage filter replacement, Membrane change, TDS calibration, and Alkaline upgrade.
   * **Air Conditioner (AC)**: Jet pump foam cleaning, Gas leak repair, PCB testing, and Inverter compressor maintenance.
   * **Refrigerator (Fridge)**: Frost-free defrost repair, Thermostat replacement, and Gas charging.
   * **Water Heater (Geyser)**: 2000W Incoloy heating element replacement, Descaling, and Thermostat calibration.

2. **Ultra-Sharp High-Contrast Typography (AAA Compliance)**:
   * Razor-sharp, dark-toned text in Light Mode (`#0b192c`, `#1e293b`, `#111827`) ensuring 100% legibility on light surfaces.
   * Crisp white text in Dark Mode (`#ffffff`, `#f8fafc`, `#f1f5f9`) on deep navy backgrounds.
   * Clear, high-contrast badges, cards, inputs, and tables across all portals.

3. **Google Maps Real-Time GPS Tracking (`GoogleMapsTracker` & `GoogleMapsCanvas`)**:
   * Authentic Google Maps street styling with road networks, water bodies, and parks.
   * Top Google Navigation Green Banner with turn-by-turn maneuvers and traffic status.
   * Blue Navigation Vehicle cursor with forward heading light cone and pulse accuracy circle.
   * Red Google Maps teardrop destination pin with drop shadow.
   * Layer switcher (Default, Satellite, Traffic), Zoom controls (`+`/`-`), and trip sharing.

4. **Geo-Tagged Camera On-Site Verification (`GeoTaggedCamera.tsx`)**:
   * Live camera capture with real-time GPS Geolocation metadata.
   * Renders tamper-proof on-site GPS watermarks (Latitude, Longitude, Accuracy, and Timestamp) directly on captured inspection photos for technician start-of-work and denial audits.

5. **Demo QR Code Generator (`DemoQrGenerator.tsx`)**:
   * Client-side SVG/Canvas QR generator for **Digital Service Verification Passes**, **UPI Direct Payment QRs**, and **Product Warranty Certificates**.

6. **Interactive 3D Appliance Engineering Lab (`Interactive3DShowcase.tsx`)**:
   * Exploded 3D view for RO Purifiers, Dual-Inverter ACs, Smart Refrigerators (Fridges), and Digital Geysers with 3D mouse rotation and layer breakdown.

7. **Complete Theme Toggle System (`ThemeToggle.tsx` & `ThemeContext.tsx`)**:
   * Smooth Sun ☀️ / Moon 🌙 toggle with persistent preference across all Customer, Vendor, and Admin portals.


### 3. Production Build
```bash
npm run build
```
